## 一、新增动作 `fetch`（`run.py` 第 9 个动作）

```
python3 tools/run.py fetch                              默认今天+昨天（＝采集窗口）
python3 tools/run.py fetch --date 2026-10-26            只抓一天
python3 tools/run.py fetch --since 2026-09-01 --until 2026-09-25   补一段
python3 tools/run.py fetch --dry-run                    只说会写哪些
python3 tools/run.py fetch --keep                       原页留在 .cache/fetch/ 便于复核
```

代码落点（分层未反向）：
| 层 | 文件 | 内容 |
|---|---|---|
| core | `pkb/core/web.py` | 取页（curl，失败重试一次）、按 meta charset 解码、标签配对取正文、找附件、判栏目页、扩展名解析 |
| core | `pkb/core/doc.py` | docx（zip+XML）／doc（textutil）／pdf（pdfminer）转文本，PDF 断行接回去 |
| core | `pkb/core/paths.py` | `RAW_DIR`／`ARTICLE_DIR`／`CACHE_DIR` |
| domain | `pkb/domain/sources.py` | **口径**：`原文`／`官方报道`／`非一手` 三级域名表 + `level()`／`archivable()`／`why()` |
| actions | `pkb/actions/fetch.py` | 编排：扫卡片窗口→判级→抓→转→写→报欠账 |

## 二、四条边界（都写进代码注释，理由在 `log.md`）

1. **只写 `raw/articles/`，不碰卡片**——卡片是采集的产物，抓取脚本改卡片会让「谁改了政策事实」变成糊涂账。
2. **只增不改**：同一 URL 已存过即跳过（幂等）；要重存先改卡片链接。
3. **无一手源的不猜**：只有二手、栏目页、404、占位链接，只报不存——把二手当一手存下来是最贵的错。
4. **欠账不阻断退出码**：`0`＝跑完了（欠账在明细里），`1`＝库不可写，`2`＝参数非法。
