## 关键脚本口径（复用）
- 断链扫描须处理 Obsidian 表格转义 `\|`（`[[政策链-XX\|XX]]` 是合法链接，非断链）。
- 链名匹配：卡片 `所属政策链` 解析后是短名（`产业政策`），链文件名为 `政策链-产业政策`，比对前去掉 `政策链-` 前缀。
- 假断链排除：templates 占位符、AGENTS/README 举例、log.md 历史旧链名。
- 词表解析陷阱：主题词表表格单元格含 `\|` 转义，须先 `replace('\\|', 占位符)` 再按 `|` split，否则词表解析错误、误报大量"不合规词"。
- 卡片 `所属政策链` 字段形如 `[[政策链-XXX]]`（含双方括号），比对链文件名前须 `replace('[[','').replace(']]','')`。
