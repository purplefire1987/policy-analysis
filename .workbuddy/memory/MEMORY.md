## 三、tools（四层）

- **分层单向**：`run.py → actions → checks → domain → core`，低层不许 import 高层。

## 五、踩过的坑（按类合并）

**判据类**
1. **自愈机制必须被验证过一次才算存在**：`--fix` 正则写全角冒号而库里用半角，从建立起没修成过也不报错。
2. **判据要认声明形态，不认文本包含**：注释含 `--fix` 就被编进修复队列；docstring 里举的例会被逐行正则当代码。用 **AST**；判据认**调用形态**，说明文字用描述性措辞（否则 `sys.exit(`、`python3 -m pkb…` 这类解释性引用会自己误伤自己）。
3. **白名单拼进识别正则会让自己失效**：`LOG_HEAD` 曾用 `'|'.join(LOG_TYPES)` 构造，类型写错的条目落进「历史条目」被静默豁免，那条报错分支从未触发——「类型限五类」等于不存在。识别放宽成任意串、白名单另查才验得出来。
4. **声明了取值范围就要有判据**：台账写「裁判只能取手册列过的」而脚本不管；加上后第一条数据就不对。名单**从文档现读、不在代码里存第二份**。
5. **宁可宁窄不错认**：全库扫 `N 节` 把 `政策链三节`、`六节历史归档` 这类**正确**写法判错。**会误伤正确写法的规则比不扫更糟**——它教人以后绕开规则。通用词（采集／体检／周观点／结构）做枚举时**别进口径扫描词典**。
6. **写死名次＝写死数量**：手册「前四项任一成立即可否掉」是补裁判前写的，后来加了裁判，判定权还锁在旧四项。**名单加长时，凡带序号的判据都要回头看一眼。**
7. **静默丢弃比报错危险**：拼错的参数照跑 exit 0，调用方以为窗口核过了。

**文档类**
8. **没有校验的副本等于迟早撒谎**：4 次事故全是库外副本漂移；**单源化本身就是修漏洞**。副本清单要按「**谁在读它**」核——专家包 README／SKILL 长期在防线外（写着旧节数、动作表漏项、教人跑已删脚本），无人报。
9. **结构化断言查不出叙述性描述**：漂移全在「脚本会自动发现」「raw 只读」这类句子——**文档漂移只能人读**，别把脚本当完整防线。「读了这个文件」≠「核对了这个文件」（`_load_docs()` 把 index 读进来却没消费它）。
10. **log 标题日期位只认单一日期**：`## 2026-10-24 ~ 10-25 · …` 匹配不上 `LOG_HEAD`，被当历史条目，其后全部新条目被判错位。区间写正文。
11. **「已归档」必须当场核文件存在**：两处写着「原样归档于 X（499 行）」而目录**根本不存在**。**写「已归档」比不写更坏**——后人以为还能查就不补了。做法：路径＋行数＋当场 `ls`。
12. **删东西前先 grep 引用，包括「同义词指路」**：删了采集流水，而「明细见采集日志」这类句子 grep 链接名抓不到，结果两份文件互相指路、谁也不含流水。
13. **改文档最容易顺手编一个看起来对的分布**：「9 条」拆成「腾讯 2、财联社 1…」是推算的没数过。**没有逐条数过就写「逐条见附表」**。
14. **带日期的相对量不是两本账**：台账两个数字常是两天时点的同一个量，断档按天自然 +1。**改数前先看是不是不同时点。**

**环境类**
15. **macOS 是 BSD grep**：`grep "a\|b"` 不支持交替，静默无输出。用 `-E` 或 Grep 工具。
16. **`HTTP_PROXY` 会让 curl 访问 localhost 返回 502 且退出码 0**：探端口用 bash `/dev/tcp` ＋ `NO_PROXY`。bash 3.2 会吞紧跟变量的全角字符（须 `${VAR}`）。
17. **并行子代理必 429**，批量补录走主通道；`%%` 注释不成对会吞正文（用 `<!-- -->`）；能点开≠能核验。
18. **止损不等于治因**：一手存档正文乱码，先加 `looks_binary()` 只拦住结果；真因是该站回 gzip 而 `curl` 没带 `--compressed`。**结果不对，往回追一层问从哪步开始不对。**
19. **osascript 删文件可能返回 -10004 而文件已进废纸篓**：以源目录文件数为准。
20. **git `index.lock` 残留时安全策略会拦 `rm`／`mv` 绕路**（`safe-delete`、`unable to write new index file`）——交给用户清，别反复试。
21. **`pytest` 全量偶发 `No usable temporary directory`**（临时目录被安全策略清）：改跑 `python3 -m pytest tools/tests -q`，别据此判定逻辑错。

## 九、人的落笔处：`raw/notes/`（2026-10-28）

**为什么在 `raw/` 下而不在 `wiki/` 下**：它不是「库的结论」，是**输入**。周观点取消判断与定稿后，人的异议要有地方写；写在产出里会被下次生成覆盖。机器只读不写。

- 一篇笔记一个文件，日期与标题在 frontmatter（`类型: 灵感｜异议` 等），**结构自由**——所以用 `scan_notes` 而不是硬套 `scan_dated`。笔记不进卡片、不进信号，**除了检索没有别的入口，进不了结果就等于没写**。
- **周观点生成时读上一期笔记，相左处并列不裁决**：`> **分歧**：〔笔记的结论〕——本刊的结论是〔…〕`，谁对由下期数据说。已写进 AGENTS 第八节、专家定义、周观点提示词。
- **合格评的是过程不是命中率**，看的是「该核的核了没有、核不动的说清了没有」。
