## 坑（每条都真踩过）
- **判据要改坏实测一次**才算写对，自愈机制同样。
- **判据不该吃被削过的字符串**：`_log_heads()` 已去掉行首 `## `，照着写正则会让两条判据一起空转、全程报绿。
- **判据逻辑错比没有更坏**：前提消失后要回头删（`check_release_logged` 替人签了两个月字）。
- **一个事实只能有一个出口**（`check_views` 与 `plan` 各报一个覆盖率）。
- **改 AGENTS 必须保留判据依赖的四串**：结构常量括号（含「七节」）、「类型限 …」、界面新闻／中华网、第一节 HH:MM。
- **不留副本**：四次事故全是库外副本漂移；结构化断言查不出叙述性描述，只能人读。没量过的量词、没核过的「已归档」不进文档。
- **往表格插整行，`old_string` 要取到行尾 `|`**：截半行会让旧行尾巴粘上来，列数不变、判据不报。
- macOS 是 BSD grep：交替用 `-E`，`\|` 静默无输出。
- 沙箱拦删会留 8 位随机名、4 字节 `blat` 探针；`check_vcs` 三重判据报红＋`fix` 自动清，不加 `.gitignore` 规则。删不掉时先原地重试，仍失败**主动问用户，不绕路不藏**。
- 留痕会改变 check 输出，自检放在留痕之后跑最后一次。
